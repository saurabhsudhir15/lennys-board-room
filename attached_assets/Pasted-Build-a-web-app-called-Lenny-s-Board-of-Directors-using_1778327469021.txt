Build a web app called "Lenny's Board of Directors" using Python and Streamlit.

## What It Does
A PM brings their toughest product problem. The app assembles a board of 5 advisors 
drawn from Lenny Rachitsky's podcast guests — each with a distinct role and philosophy. 
The board debates the problem and delivers a synthesis. Every insight is grounded in 
real content from Lenny's archive.

## File Structure
One file, one job. Keep it clean so anyone can update without touching logic they 
don't understand:

```
app.py           — Streamlit UI only, zero business logic
board.py         — board assembly (retrieval + LLM calls)
ingest.py        — standalone ingestion script, run once from shell
config.py        — ALL editable settings: models, roles, guest titles
requirements.txt
lenny-data/      — cloned Lenny repo (auto-generated)
```

## Data Setup
lenny-data/ contains:
- podcasts/ — 50 markdown files, full podcast transcripts
- newsletters/ — 10 markdown files, newsletter posts

Each file has YAML frontmatter (title, date, type, guest, description) followed by content.

## ingest.py
Standalone script. Run once: `python ingest.py`

Steps:
1. If lenny-data/ not present, clone:
   git clone https://github.com/LennysNewsletter/lennys-newsletterpodcastdata.git lenny-data
2. Check Supabase lenny_chunks row count — if > 0, print "Already ingested. Skipping." and exit
3. Read all markdown files from podcasts/ and newsletters/
4. Parse YAML frontmatter: title, guest (use "Lenny's Newsletter" for newsletter type), date, type, description
5. Strip frontmatter, keep clean content
6. Chunk each document into ~500 word chunks with 100 word overlap
7. For each chunk, generate embedding using OpenAI text-embedding-3-small 
   with dimensions=1536 from config.EMBED_DIMENSIONS
8. Insert into Supabase: content, embedding, guest_name, title, type, date, description
9. Print progress: "Ingested X/60 files..."

## board.py
All board logic. Import config values — never hardcode models or settings here.

### Token + cost tracking
Every LLM call must log usage. Create a simple logger:

```python
def log_call(task, model, input_tokens, output_tokens):
    pricing = config.MODEL_PRICING.get(model, {"input": 0, "output": 0})
    cost = (input_tokens / 1_000_000 * pricing["input"]) + \
           (output_tokens / 1_000_000 * pricing["output"])
    entry = {
        "task": task,
        "model": model,
        "input_tokens": input_tokens,
        "output_tokens": output_tokens,
        "cost_usd": round(cost, 6)
    }
    # append to st.session_state["call_log"] list
    return cost
```

### analyze_problem(problem: str) -> dict
Call OpenAI with config.ANALYSIS_MODEL. Log the call.
Return: problem_type (one of: metrics/growth, prioritization, stakeholder management,
go-to-market, execution, product strategy, team/culture, product-market fit)
and search_queries (list of 3-5 strings).

### retrieve_chunks(search_queries: list) -> list
For each query, generate embedding via OpenAI text-embedding-3-small.
Call Supabase match_chunks. Combine results, deduplicate by guest_name,
keep highest similarity chunk per guest. Return top 10.

### select_board(problem, chunks) -> list
Call OpenAI with config.ANALYSIS_MODEL. Log the call.
Select 5 distinct guests, assign each a role from config.BOARD_ROLES.
Match roles to guest expertise. Return list of 5 dicts:
{guest_name, role, chunk_content, title, date}
Fallback to config.FALLBACK_GUESTS if fewer than 5 guests found.

### generate_board_response(guest_name, role, role_description, chunk, problem) -> str
Call OpenAI with config.BOARD_MEMBER_MODEL. Log the call.

System: "You are {guest_name}, speaking from your experience as a product leader 
and your appearances on Lenny's Podcast. Your board role is {role}: {role_description}. 
Speak in your authentic voice. Be direct, specific, reference your actual frameworks. 
You have a distinct point of view — you do not need to agree with others."

User: "A PM has brought this problem to the board: {problem}

The most relevant insights from your conversations with Lenny:
{chunk}

Give your board perspective in 150-180 words. Lead with your sharpest insight. 
Be opinionated. End with one specific action."

### generate_all_responses(board_members, problem) -> list
Run generate_board_response for all 5 members in parallel using 
concurrent.futures.ThreadPoolExecutor(max_workers=5).
Return responses in same order as board_members.

### generate_debate(board_members, responses) -> str
Call OpenAI with config.BOARD_MEMBER_MODEL. Log the call.
Find the two most philosophically opposed members. Generate 2-3 sentence tension.
Format: "[Guest A] pushes back on [Guest B]: ..."

### generate_synthesis(problem, board_members, responses) -> str
Call OpenAI with config.SYNTHESIS_MODEL. Log the call.
Return 3 paragraphs:
- What the board agrees on
- The key tension they did not resolve — the PM must decide
- The single most important next action

## app.py
Streamlit UI only. Import from board.py and config.py. Zero logic here.

Initialise session state on load:
- st.session_state["call_log"] = []
- st.session_state["board_result"] = None

Color scheme: deep navy (#0D1B2A) background, gold (#C9A84C) accents, white text.
Apply via st.markdown custom CSS block at top.

LANDING STATE:
- Header: "Lenny's Board of Directors" large bold
- Subheader: "Bring your toughest product problem. Your board — assembled from 
  Lenny's podcast guests — will debate it."
- Large st.text_area, placeholder: "Describe your product problem. 
  The more specific you are, the sharper the advice."
- 4 clickable chips from config.EXAMPLE_PROBLEMS — clicking autofills the text area
- Gold button: "Assemble Your Board"
- On startup: check Supabase row count. If 0, show warning banner: 
  "Run python ingest.py in the shell to load Lenny's archive."

LOADING STATE (show sequentially):
- "Reading your situation..."
- "Scanning 50 episodes for the right advisors..."
- "Assembling your board..."
- "Preparing their perspectives..."

BOARD STATE:
- "Your Board" header with gold divider
- 5 board member cards in 3-column then 2-column grid (st.columns)
- Each card:
  - Role badge: colored pill using color from config.BOARD_ROLES
  - Guest name bold + title from config.GUEST_TITLES in smaller muted text
  - 150-180 word response
  - Italic citation: "— {guest_name}, Lenny's Podcast"
- "The Debate": gold left-border callout box
- "Board Synthesis": white card, dark text, 3 labeled paragraphs:
  "What the board agrees" / "The open question" / "Your next move"
- Collapsed st.expander "Sources": all 5 guests with episode title + date
- Collapsed st.expander "Session Stats":
  - Table of each LLM call: task, model used, tokens, cost
  - Total session cost in bold
- Button: "Bring a new problem" — resets session_state, reruns

## Important Notes
- No sentence-transformers — OpenAI handles all embeddings
- ingest.py is standalone — NOT imported by app.py
- All 5 board member calls run in parallel via ThreadPoolExecutor
- session_state persists board results across Streamlit reruns
- Budget guardrail is silent — user never sees a downgrade message, 
  only visible in Session Stats expander
- App runs on port 8501
